Open Firewall Access from Bitbucket DR & Production Node 2 to Jenkins (Webhook Communication)




Enable Bitbucket webhook communication from the Bitbucket DR server and Production Node 2 to Jenkins for automated CI/CD pipeline triggering.




As part of the Bitbucket High Availability (Production Node 2) and Disaster Recovery (DR) implementation, firewall access is required from the Bitbucket DR server and Bitbucket Production Node 2 to the Jenkins server.

This connectivity is required to enable Bitbucket webhooks, allowing repository events (e.g., push and pull request activities) to trigger Jenkins pipelines as per the existing Production Node 1 configuration.

Kindly open the required firewall access from:

* Bitbucket Production Node 2 → Jenkins
* Bitbucket DR Server → Jenkins

using the same protocol and port(s) as the existing Bitbucket Production Node 1 to Jenkins communication.
