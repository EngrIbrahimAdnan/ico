Requesting Information Security assessment for the upgraded Nexus Repository 3.95.0-07 environment prior to production promotion.

The new Nexus server will be deployed on a **separate, dedicated production IP address** and will operate independently from the existing production Nexus server. The existing production Nexus server and its current IP will remain operational and will not be modified as part of this activity.

The environment has been configured and initially validated in staging, including connectivity to the external PostgreSQL database, user access, VDI accessibility, and GitHub connectivity.

Security assessment is required to validate the new production server and identify any security findings that must be remediated or formally addressed before proceeding with the CAB-approved production promotion.

The assessment is therefore requested for the **new Nexus 3.95.0-07 production server/IP** and not the existing production Nexus environment.
