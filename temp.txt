# 2. Commissioning Ticket

### Title

**Commission Nexus Repository UAT Server – Filesystem Configuration**

---

### Description

Please configure the filesystems for the approved Nexus Repository UAT server as follows:

| Mount Point      |                                          Size |
| ---------------- | --------------------------------------------: |
| `/`              |                                        100 GB |
| `/home`          |                                         10 GB |
| `/tmp`           |                                         10 GB |
| `/var`           |                                         20 GB |
| `/var/log`       |                                         20 GB |
| `/var/log/audit` |                                         10 GB |
| `/u01`           | Remaining capacity (approximately **450 GB**) |

### Purpose

The server will host the **Nexus Repository OSS v3.93.2** UAT environment.

The `/u01` filesystem will be used as the **initial Nexus blob store** for repository artifacts during installation, validation, and phased migration activities.

At a later stage, a separate request will be raised to expand `/u01` to **4 TB**, with future scalability to **8 TB**, to support the complete production repository migration.

No external PostgreSQL storage is required as part of this request, as the database will be provisioned separately on the centralized PostgreSQL platform.
