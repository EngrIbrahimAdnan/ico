# Firewall Access Request – GitHub HTTPS Connectivity for Nexus SPM Testing

**Source:** Nexus UAT server
**Destination:** GitHub endpoints
**Protocol/Port:** HTTPS / TCP 443
**Direction:** Outbound

## Description

Request outbound HTTPS connectivity from the Nexus UAT server to the required GitHub endpoints to support testing of **Swift Package Manager (SPM) repository functionality** introduced in Nexus Repository 3.95.0-07.

The SPM proxy workflow may access GitHub repositories and subsequently redirect package/content downloads to additional GitHub-hosted endpoints. The following destinations are therefore required:

* `github.com`
* `api.github.com`
* `codeload.github.com`
* `*.githubusercontent.com` (including `objects.githubusercontent.com`)

This connectivity is required to validate end-to-end Swift package discovery, download, proxying, and caching through the Nexus UAT Swift repository.

The access is **outbound HTTPS only** from the Nexus UAT server; no inbound connectivity from GitHub to the Nexus server is required.
