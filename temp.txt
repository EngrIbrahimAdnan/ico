**Configure Microsoft Entra ID (OIDC) Application for IBM DevOps Deploy (UAT)**


### Objective

Configure Microsoft Entra ID (OpenID Connect) integration for the IBM DevOps Deploy (UCD) UAT environment by creating the required application registration and providing the OIDC configuration details.

### Required Information

Please create/configure the Microsoft Entra ID application for UCD UAT and provide the following:

* Client ID
* Client Secret
* Issuer URL
* JWKS URI
* Authorization Endpoint
* Token Endpoint
* UserInfo Endpoint
* End Session Endpoint

### Token Claims

Please confirm or configure the following standard claims (or advise if different values are required by our organization):

* Username Claim: `preferred_username`
* Name Claim: `name`
* Email Claim: `email`

### Scopes

Please confirm the application supports the following scopes:

* `openid`
* `profile`
* `email`

### Notes

These values will be used to configure the OpenID Connect authentication realm within the IBM DevOps Deploy UAT environment. If additional configuration is required on the Entra ID side (such as redirect/callback URIs, application permissions, or claim mappings), kindly provide the necessary details.
